# DEV-008.1 - Recommendation comparison archive-view helper

- **Parent Item:** DEV-008 - Add a bounded archive-usability helper for recommendation comparison artifacts
- **Entry Point:** PRE_IMPLEMENTATION_VERIFICATION
- **Status:** READY FOR PRECHECK
- **Created:** 2026-07-04
- **Scope Type:** Lean Dev / bounded archive-view helper slice

## Goal

Define the first lightweight local archive-view helper that turns one saved recommendation comparison artifact into a stable review-friendly archive view without adding live helper runtime, automation, or delegated authority.

## Required Outcome

Create one small Dev helper slice that can take one bounded comparison artifact and produce one archive-friendly summary artifact for the already-approved recommendation preparation and comparison path.

## In Scope

- define one small archive-view output shape for one saved comparison artifact
- preserve labels, favorite models, timestamps, suggested next actions, and approval-boundary wording needed for later review
- keep the helper or artifact local-only and deterministic for this first slice
- stay compatible with the comparison-artifact contract from `DEV-007.1`

## Out Of Scope

- live MCP fetches
- recommendation synthesis
- automatic model selection
- automatic live-run continuation
- executor/runtime changes
- production routing activation
- repo-write delegation
- delegated final validation authority
