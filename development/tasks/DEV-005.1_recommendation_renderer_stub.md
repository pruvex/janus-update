## Goal

Define the first lightweight local renderer/stub that fills the locked MCP recommendation template from one bounded structured input package without adding live helper runtime, automation, or delegated authority.

## Required Outcome

Create one small Dev helper slice that can take a fixed recommendation input package and render one stable markdown artifact in the already-approved operator-facing template shape.

## In Scope

- define one small structured input shape for the renderer/stub
- render the favorite-first recommendation format in stable markdown order
- include 1 to 2 alternatives below the favorite
- preserve the short reason, recommended next action, and approval-boundary language
- keep the output archivable for later comparison
- keep the helper local-only and deterministic for this first slice

## Out Of Scope

- live MCP fetches
- automatic model selection
- automatic live-run continuation
- executor/runtime changes
- production routing activation
- repo-write delegation
- delegated final validation authority
