- **Status:** READY FOR PRECHECK

- **Scope Type:** Lean Dev / bounded routing-calibration helper slice

## Goal

Define one small local helper that compares current tri-modal routing cost defaults against already recorded local delegation evidence and renders a stable calibration report without changing routing files automatically.

## Required Outcome

Create one bounded Dev helper slice that can read the current delegation manifest/task list plus known local OR evidence files and produce one calibration report with observed costs, configured defaults, and conservative suggested adjustments for Codex review.

## In Scope

- read the current tri-modal routing manifest and task list locally
- collect bounded existing delegation evidence from known local run artifacts only
- compare configured prompt-cost estimates and confidence values against observed actual costs
- render one stable JSON or Markdown calibration report for Codex/operator review
- keep the helper local-only and deterministic for this first slice

## Out Of Scope

- live Cursor or OpenRouter calls
- automatic manifest or task-list rewrites
- production routing activation
- recommendation authority changes
- repo-write delegation
- delegated final validation authority
- broad telemetry migrations or new runtime capture layers
