## Goal

Define the first lightweight local input-prep helper that assembles the structured recommendation package for the renderer from one bounded local evidence bundle without adding live helper runtime, automation, or delegated authority.

## Required Outcome

Create one small Dev helper slice that can take a fixed local evidence bundle and produce one renderer-ready structured package for the already-approved recommendation renderer path.

## In Scope

- define one small structured evidence/input shape for the prep helper
- map bounded local evidence fields into the renderer-ready package with stable keys
- preserve favorite-first recommendation ordering requirements
- preserve alternatives, short reason, recommended next action, and approval-boundary inputs needed by the renderer
- keep the helper local-only and deterministic for this first slice

## Out Of Scope

- live MCP fetches
- automatic model selection
- automatic live-run continuation
- executor/runtime changes
- production routing activation
- repo-write delegation
- delegated final validation authority
